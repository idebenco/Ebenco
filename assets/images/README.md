- **favicon.png** - Website favicon (32x32px or 16x16px)
- **logo.png** - Company logo (optional, if you want to replace text logo)

## Image Specifications

### Recommended Sizes
- **Product Images**: 800x800px (square format)
- **Favicon**: 32x32px or 16x16px
- **Logo**: 200x60px (if using image logo)

### Format
- Use JPEG for photos (smaller file size)
- Use PNG for logos and graphics with transparency
- Use WebP for modern browsers (optional)

### Optimization
- Compress images before uploading
- Keep file sizes under 200KB for fast loading
- Use descriptive filenames (lowercase, hyphen-separated)

## Fallback Images

The website includes inline SVG fallbacks if images are not found. However, for the best user experience, please upload all product images.

## Notes

- All images are referenced in the HTML with fallback SVG placeholders
- The website will work without images but will look better with them
- Consider using high-quality, professional product photography
- Ensure images are properly licensed for commercial use
